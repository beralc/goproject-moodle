El chatbot Edelvives4U dentro del proyecto

El chatbot Edelvives4U está disponible en la esquina inferior derecha. Cuando estás dentro de un proyecto, responde sobre ese proyecto y te ayuda a prepararlo.

Buscar recursos para una fase

Ejemplo: «Búscame recursos sobre imanes para una de las fases de este proyecto.» Te propone recursos que puedes añadir directamente.

Propuesta de temporalización

Ejemplo: «¿Cómo reparto las sesiones entre las fases de este proyecto?» Útil tras adaptar el proyecto a tu número de sesiones.

Adaptaciones para necesidades específicas

Ejemplo: «¿Cómo adaptaría esta actividad para un alumno con dislexia?» Te sugiere ajustes concretos. En el Módulo 3 verás cómo GoProject gestiona la inclusión de forma sistemática (adaptaciones NUBO, integración con RedduAPP).

Fuera de un proyecto, el chatbot funciona como asistente general de la plataforma (ideas, catálogo de Edelvives, dudas de uso).
