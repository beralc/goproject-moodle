El chatbot Edelvives4U dentro del proyecto

El chatbot Edelvives4U está disponible en cualquier momento desde el icono de la esquina inferior derecha de la pantalla. Cuando estás dentro de un proyecto, el chatbot tiene funciones específicas que pueden acelerar tu trabajo de edición.

Qué puedes pedirle cuando estás editando un proyecto

Buscar recursos para una fase

Ejemplo de consulta: «Búscame recursos sobre el comercio sostenible en la Edad Media para una tarea de 6º de Primaria.»

El chatbot te propone recursos que puedes añadir directamente a la fase de Desarrollo.

Ideas para presentar el proyecto al alumnado

Ejemplo de consulta: «Dame tres ideas para presentar el reto de este proyecto de forma motivadora a un grupo de 4º de ESO.»

Útil para enriquecer el bloque Reto de la Motivación.

Propuesta de temporalización

Ejemplo de consulta: «¿Cómo distribuiría 18 sesiones entre las cinco fases de este proyecto?»

El chatbot propone una distribución que puedes usar como referencia para ajustar tus tareas.

Adaptaciones para necesidades específicas

Ejemplo de consulta: «¿Cómo adaptaría la tarea 2 para un alumno con dislexia?»

El chatbot sugiere ajustes concretos. En el Módulo 3 verás cómo GoProject gestiona la inclusión de forma sistemática a través de su integración con Nubo de Redwap.
