Opciones del proyecto: Impresión On Demand y Solucionario

Una vez publicado el proyecto, aparece el botón «Opciones del proyecto» con un caret (▼) que despliega las opciones disponibles. Este menú contiene exactamente dos opciones.

Opción 1: Impresión On Demand

Esta opción genera un cuaderno imprimible bajo demanda para el alumnado. Tú decides qué incluye:

  • Solo actividades: incluye todas las actividades del proyecto (las de Investiga y aprende, las de ¿Qué sabemos? y las de Síntesis), pero no el contenido teórico.
  • Actividades + contenido teórico de saberes básicos: incluye también el corpus editorial de Edelvives que seleccionaste en el paso 8 del proceso de creación. El alumnado tiene en un único documento tanto la parte práctica como el apoyo conceptual.

Activa las opciones según las necesidades de tu grupo y haz clic en «Previsualizar». El sistema genera un documento imprimible que funciona como un cuaderno de trabajo del estudiante. Revisa la previsualización para confirmar que el documento tiene el formato y el contenido que esperas.

Cuando estés conforme, haz clic en «Iniciar el proceso» para recibir asesoramiento sobre la impresión bajo demanda del cuaderno.

Cuándo usar Impresión On Demand:

  • Si trabajas en un aula con acceso limitado a dispositivos y el alumnado necesita el material en papel.
  • Si quieres ofrecer una versión impresa del proyecto como complemento al entorno digital.
  • Si el centro tiene presupuesto para impresión bajo demanda y quieres un cuaderno de trabajo de calidad editorial.

Opción 2: Descargar Solucionario

Al hacer clic obtienes un PDF con las respuestas a todas las actividades autoevaluativas del proyecto: desde la fase de Activación hasta la Síntesis. Este documento es para el docente, no para el alumnado.

El Solucionario es útil para:

  • Tener la corrección a mano durante las sesiones de clase.
  • Facilitar la corrección cuando el proyecto se usa como evaluación sumativa.
  • Compartir con otros docentes que usen el mismo proyecto.
